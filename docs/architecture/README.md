# Architecture authorities

The DOCX here is an unchanged copy of the original specification. The text file is
its readable paragraph/table export for focused review. The immutable original and
its hash remain under `project-management/baseline/`. PC-001 overrides only the
explicitly accepted planning/bootstrap conflicts; it does not waive physical gates.

The detailed external source-plan appendices and built controller source were not
available at bootstrap. Work that needs their exact contracts must record that
missing input rather than invent a final protocol or measured geometry.
